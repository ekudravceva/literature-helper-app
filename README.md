# Приложение "Литературный помощник"

Приложение для формирования персонализированных книжных рекомендаций и отслеживания годовых целей по чтению.

Разработано в рамках курсовой работы.

## Ключевые возможности

- **Свайпы книг** — выбор книг жестами или кнопками в Tinder-подобном интерфейсе
- **Персональные рекомендации** — алгоритм контентной фильтрации на основе лайкнутых жанров и авторов
- **Читательский дневник** — списки «Хочу прочитать», «Читаю сейчас», «Прочитано»
- **Годовые цели** — установка цели по количеству книг и отслеживание прогресса
- **Детальная информация** — модальное окно с полным описанием книги и кнопками статусов

## Технологии

- Бэкенд: Python 3.13, FastAPI, SQLAlchemy, PostgreSQL, Redis 
- Фронтенд: React 19, React Router, Axios 
- Инфраструктура: Docker, Docker Compose, Nginx 

## Быстрый запуск

### Требования

- [Docker](https://www.docker.com/) и Docker Compose

### Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/ekudravceva/literature-helper-app
cd literature-helper-app
```

2. Создайте файл `.env` в корне проекта и добавьте ключ Google Books API:

```
GOOGLE_BOOKS_API_KEY=ваш_ключ
```

3. Запустите приложение одной командой:

```bash
docker-compose up -d --build
```

4. Загрузите книги в базу данных:

```bash
docker-compose exec backend python load_books.py
```

5. Откройте приложение в браузере:

```
http://localhost:3000
```

### Остановка

```bash
docker-compose down
```

Данные пользователей сохраняются между перезапусками.

Для полной очистки (включая базу данных):

```bash
docker-compose down -v
```

## Алгоритм рекомендаций

В приложении используется алгоритм контентной фильтрации. Профиль вкуса пользователя строится на основе жанров и авторов лайкнутых книг. Каждой книге-кандидату присваивается оценка релевантности по формуле:

```
score = (веса_жанров × 3.0) + (веса_авторов × 2.0)
```

Для предотвращения «зацикливания» 30% рекомендаций составляют книги из любимых жанров, но не из самого топа выдачи (управляемая случайность).
